# 용알 쟁탈전

불꽃여우와 서리여우가 별빛 부유섬에서 용알을 깨우는 2인 온라인 3D 게임.
땅따먹기 + 꼬리잡기 + 서바이벌(유성우, 용의 숨결, 섬 붕괴).

- 방장: "방 만들기" → "링크 복사" → 친구에게 전송
- 친구: 링크를 열면 바로 입장
- 조작: 화면 왼쪽 드래그로 이동, "잡기" 버튼으로 돌진 (PC: WASD + 스페이스)
